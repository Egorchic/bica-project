# BICA — Abductive Self-Reflection

Исследовательский прототип когнитивной архитектуры абдуктивного рассуждения на основе больших языковых моделей.

Проект команды 14-524 по дисциплине «Биологически мотивированные когнитивные архитектуры», НИЯУ МИФИ.

## Архитектура

Одна языковая модель (Qwen3:14b через Ollama) последовательно выполняет несколько ролей:

- генерация конкурирующих гипотез либо приём готовых альтернатив;
- оценка гипотез относительно наблюдений (SUPPORT / CONTRADICT / UNKNOWN);
- выбор объяснения, в том числе голосованием;
- рефлексивная проверка с возможностью одного повторного цикла;
- сохранение состояния и истории решений в пределах сценария.

Программный контроллер управляет этапами. Веса модели не изменяются, память не переносится между независимыми заданиями. Эталонные ответы используются только для оценки результатов, а не в промптах. Для Belief-R, αNLG и MuSR предусмотрены специализированные адаптации агентного цикла.

## Установка

Требуются Python 3.10+ и установленный [Ollama](https://ollama.com/). Команды ниже выполняются из корня репозитория в PowerShell.

```powershell
git clone https://github.com/Egorchic/bica-project.git
cd bica-project
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[experiment,test]"
ollama pull qwen3:14b
python -m pytest -q
```

Ollama должен быть запущен. Для удалённого сервера замените значение `--host` на его адрес. В демонстрационном `examples/smoke.py` адрес сервера задан непосредственно в коде; перед запуском укажите свой адрес.

## Экспериментальный протокол

Основное исследование выполнено на 500 заданиях четырёх бенчмарков. Параметры модели: Qwen3:14b, think=True, температура 0,6, лимит генерации 2400 токенов; контекст 4096 токенов (8192 для MuSR). Начальные значения генераторов: 42 для выборки и 2026 для генерации.

| Бенчмарк | Выборка | Конфигурации |
|---|---:|---|
| αNLI (ART) | 300 | C0–C5 |
| Belief-R | 50 | B0–B2 |
| αNLG (GEM/ART) | 100 | G0–G2 |
| MuSR | 50 | M0–M1 |

### αNLI — абляция

| Режим | Компоненты | Accuracy, % |
|---|---|---:|
| C0 | Один прямой ответ | 85,3 |
| C1 | Три прямых ответа и голосование | 83,3 |
| C2 | Оценка гипотез и один выбор | 74,7 |
| C3 | Оценка, один выбор и рефлексия | 71,3 |
| C4 | Оценка и три голоса | 70,0 |
| C5 | Оценка, три голоса и рефлексия | 66,7 |

Основная выборка исключает первые 30 пилотных примеров в детерминированном порядке. В исследовании она была рассчитана двумя частями по 150 заданий:

```powershell
python -m experiments.run_anli_suite --host http://127.0.0.1:11434 --run-id anli_main_part1 --configs C0,C1,C2,C3,C4,C5 --count 150 --offset 30 --sample-seed 42 --generation-seed 2026 --model qwen3:14b --temperature 0.6 --num-ctx 4096 --num-predict 2400
python -m experiments.run_anli_suite --host http://127.0.0.1:11434 --run-id anli_main_part2 --configs C0,C1,C2,C3,C4,C5 --count 150 --offset 180 --sample-seed 42 --generation-seed 2026 --model qwen3:14b --temperature 0.6 --num-ctx 4096 --num-predict 2400
```

### Belief-R — пересмотр убеждений

B0 — прямой ответ на каждом временном шаге; B1 — оценка новой посылки, три голоса и история решения; B2 — B1 с рефлексией. Выборка включает по 25 сценариев Belief Update и Belief Maintain.

```powershell
python -m experiments.run_belief_r_suite --host http://127.0.0.1:11434 --run-id belief_r_main_50 --configs B0,B1,B2 --count 50 --sample-seed 42 --generation-seed 2026 --model qwen3:14b --temperature 0.6 --num-ctx 4096 --num-predict 2400
```

### αNLG — генерация объяснений

G0 — прямая генерация; G1 — три кандидата, оценка и три голоса; G2 — G1 с рефлексией.

```powershell
python -m experiments.run_anlg_suite --host http://127.0.0.1:11434 --run-id anlg_main_100 --configs G0,G1,G2 --count 100 --offset 0 --sample-seed 42 --generation-seed 2026 --model qwen3:14b --temperature 0.6 --num-ctx 4096 --num-predict 2400

python -m pip install -r requirements_anlg_metrics.txt
python -m pip install bert-score
python -m experiments.score_anlg results/anlg/anlg_main_100 --bertscore
```

### MuSR — многошаговое рассуждение

M0 — прямой ответ; M1 — перечень свидетельств, три голоса и рефлексия. Выборка: 17 murder mysteries, 17 object placements и 16 team allocation.

```powershell
python -m experiments.run_musr_suite --host http://127.0.0.1:11434 --run-id musr_main_50 --configs M0,M1 --count 50 --offset 0 --sample-seed 42 --generation-seed 2026 --model qwen3:14b --temperature 0.6 --num-ctx 8192 --num-predict 2400
```

## Основные результаты

| Бенчмарк | Прямой ответ | Полная конфигурация |
|---|---:|---:|
| αNLI, Accuracy | 85,3% (C0) | 66,7% (C5) |
| Belief-R, Accuracy на всех сценариях | 48,0% (B0) | 38,0% (B2) |
| αNLG, BERTScore F1 | 0,9084 (G0) | 0,8965 (G2) |
| MuSR, Accuracy | 64,0% (M0) | 58,0% (M1) |

Для задач выбора некорректно завершённые попытки учитываются как ошибки в общей Accuracy. Метрики αNLG рассчитаны среди валидных генераций: 99/100 для G0, 84/100 для G1, 77/100 для G2; эти подвыборки различаются. Для Belief-R сводки раннера также содержат метрики среди валидных сценариев — их не следует смешивать с точностью на полной выборке.

Исходная гипотеза о повышении качества за счёт исследованных механизмов не подтвердилась в данных условиях. На αNLI наблюдалось статистически значимое снижение точности при добавлении оценки гипотез. На Belief-R ни одна конфигурация не решила сценарии Belief Update. На MuSR различие между M0 и M1 статистически незначимо. Увеличение числа вызовов модели сопровождалось ростом вычислительных затрат и частоты незавершённых ответов.

## Результаты запусков и воспроизводимость

Раннеры сохраняют результаты в `results/<benchmark>/<run-id>/`: manifest, отдельные JSON с ответами и промежуточными результатами, итоговые сводки. Для αNLG отдельный скрипт создаёт `standard_metrics.json` и CSV с текстовыми метриками.

Запуск можно прервать и продолжить той же командой. Уже сохранённые задания пропускаются. Для нового протокола или изменённых параметров используйте новый `--run-id`. Не изменяйте исходники в процессе эксперимента: проверки SHA256 чувствительны даже к изменениям LF/CRLF. Фиксация начальных значений не гарантирует побитовую воспроизводимость инференса.

## Ограничения

- Оценка и самокритика выполняются той же моделью и могут воспроизводить её ошибки.
- Голосование по общему набору оценок не является полной репликацией Self-Consistency; рефлексия и память также представляют адаптации идей Self-Refine и Reflexion.
- При длинных цепочках вызовов повышается риск достижения лимита генерации и ошибки формата.
- Результаты относятся к конкретной модели, промптам, выборкам и вычислительным ограничениям; они не устанавливают неэффективность когнитивных архитектур в целом.
